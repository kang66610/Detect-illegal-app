# 《认定方法》逐项自动化覆盖审计

依据：[认定方法全文](认定方法-国信办秘字〔2019〕191号-全文.md)。官方六大类共 31 个具体认定情形。

状态含义：

- **已实现（证据型）**：真实模式可采集相应证据；未采集到证据不等同于“App 合规”。
- **待实现**：当前不能据此输出真实模式的违规结论，避免误报。
- **服务端/人工核验**：单凭 APK 客户端遍历无法完成，需要接口日志、后台记录或人工测试。

## 当前规则库使用原则

当前 `identification_method_rules.yaml` 保留六大类的基础规则，用于已采集到的证据匹配；生产系统只运行 Appium、Frida、大模型和外部静态分析组成的真实检测管线。任何“待实现”或“服务端/人工核验”情形均显示为**未覆盖/需复核**，不能显示为“未发现违规”。
